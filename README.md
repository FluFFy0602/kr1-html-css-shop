# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара (открывается как `product.html?id=nova-x5`);
- `order.html` — страница оформления заявки (можно открыть сразу с товаром: `order.html?product=tab-10`);
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — открытие модального окна и обработка формы заявки;
- `js/products.js` — данные товаров для страницы товара;
- `js/product.js` — вывод выбранного товара на `product.html`;
- `js/order.js` — список товаров и выбранный товар на `order.html`;
- `images/` — иллюстрации категорий товаров (SVG);
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- JavaScript (минимально: модальное окно и обработка формы);
- Git;
- GitHub.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню `site-nav__list`;
- Flexbox для внутренней структуры карточек товаров `product-card`;
- Flexbox для кнопок формы `order-form__actions`;
- CSS Grid для сетки товаров `products-grid` на главной и в каталоге;
- CSS Grid для страницы каталога `catalog-layout` («фильтры + товары») через `grid-template-areas`;
- CSS Grid для формы фильтров `filters-form`.

## Позиционирование

- `position: relative` — карточка товара `product-card`, относительно неё размещается бейдж;
- `position: absolute` — бейджи «Хит», «Новинка», «Скидка» `product-card__badge` в углу карточки;
- `position: fixed` — кнопка «Наверх» `scroll-top`, остаётся на месте при прокрутке;
- `z-index` — кнопка «Наверх» отображается поверх содержимого страницы.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `hero` — первый экран главной страницы;
- `section` — раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `aside-info` — дополнительный информационный блок;
- `success-message` — сообщение об успешной отправке;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `scroll-top` — кнопка «Наверх»;
- `site-footer` — подвал сайта.

Модификаторы:

- `site-nav__link--active` — активный пункт меню;
- `product-card--featured` — выделенная карточка товара;
- `product-card--discount` — карточка товара со скидкой;
- `button--primary` — основная кнопка;
- `button--secondary` — второстепенная кнопка.

Страницы сайта связаны относительными ссылками, поэтому работают и без веб-сервера.

## Страницы сайта

- `index.html` — главная: hero-блок, преимущества, популярные товары, модальное окно заявки;
- `catalog.html` — каталог из 15 товаров пяти категорий (смартфоны, ноутбуки, планшеты, наушники, аксессуары) с блоком фильтров, кнопка «Подробнее» открывает карточку товара;
- `product.html` — карточка товара: изображение, описание, цена, наличие, таблица характеристик и кнопка заявки; для неизвестного `id` показывается сообщение «Товар не найден»;
- `order.html` — оформление заявки: форма на странице (товар из списка с группами по категориям, имя, e-mail, телефон с маской, дата, тема, комментарий, согласие); недоступные товары в списке отключены;
- `contacts.html` — контактная информация и переход к форме заявки.

Все страницы используют общую шапку, меню и `css/style.css`. У каждой страницы свои `title` и `meta description`.

## Самостоятельные доработки

- Расширенный каталог: 15 карточек (список длиннее экрана, поэтому хорошо виден sticky-фильтр) с разными вариантами через БЭМ-модификаторы (`product-card--featured`, `product-card--discount`, `product-card--unavailable`) и бейджами.
- Sticky-фильтр: блок `catalog-filters` остаётся на экране при прокрутке списка товаров (`position: sticky`).
- Дополнительные состояния: `:active` у кнопок, тень у карточки при наведении, недоступный товар с неактивной кнопкой (`:disabled`).
- Блок «Частые вопросы» на главной: 10 вопросов в трёх группах (заявка, каталог и товары, о сайте) с подробными ответами, списками и ссылками на другие страницы; раскрывающиеся ответы на `<details>` и `<summary>` без JavaScript (БЭМ-блок `faq`), пункт «Частые вопросы» в меню с якорем `#faq`.
- Блок «Отзывы» на главной: БЭМ-блок `review-card` с модификатором `review-card--accent`, сетка на Grid. В карточке есть аватар с инициалом, город, рейтинг в звёздах (с `aria-label` для скринридеров) и кавычка перед текстом, при наведении карточка приподнимается.
- Маска телефона в форме заявки: при вводе «7» появляется «+7», затем автоматически ставятся скобки, пробел и дефисы (`+7 (900) 000-00-00`), номер можно начинать с 7, 8 или сразу с кода оператора, каретка при правке в середине не прыгает.
- Доступность формы заявки: подсказка телефона связана с полем через `aria-describedby`, обязательные поля отмечены «звёздочкой» с пояснением, у сообщения об успехе `aria-live`.
- Улучшенное модальное окно: закрытие кликом по затемнённому фону и анимация появления (с учётом `prefers-reduced-motion`), в окне показан выбранный товар, фон страницы не прокручивается, а при нехватке высоты окно прокручивается, и кнопки внизу остаются на виду. Оформление окна: цветная верхняя полоса, тень и размытый фон, шапка с кнопкой «×», подсветка поля при фокусе, зелёная рамка у корректных и красная с розовым фоном у ошибочных полей, свой значок у списка выбора темы, основная кнопка на всю ширину.
- Плавная прокрутка к якорям и подсветка цели якоря (`:target`).
- Кнопка «Наверх» с `position: fixed`.
- Хлебные крошки на внутренних страницах.
