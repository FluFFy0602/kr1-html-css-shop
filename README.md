# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `js/main.js` — открытие модального окна и обработка формы заявки;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- JavaScript (минимально: модальное окно и обработка формы);
- Git;
- GitHub.

## Архитектура CSS

- дизайн-токены (цвета, отступы, радиусы, ширина контейнера) вынесены в CSS-переменные в `:root`;
- классы названы по БЭМ: блок `product-card`, элемент `product-card__title`, модификатор `button--secondary`;
- файл `css/style.css` упорядочен: токены → базовые стили → блоки → состояния.

## Состояния интерактивных элементов

- `:hover` — ссылки меню, кнопки, карточки товаров, поля формы;
- `:focus-visible` — единая обводка для навигации с клавиатуры;
- `:active` — нажатие на ссылки меню и кнопки;
- `:disabled` — недоступные кнопки и поля формы;
- `aria-invalid="true"` — поля формы с ошибкой;
- `aria-current="page"` и `--current` — текущий пункт меню.

## Реализованные элементы интерфейса

- модальное окно с формой заявки;

- базовая JS-обработка формы;
